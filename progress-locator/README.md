# Progress Locator

中文名称：定位仪

## Purpose

帮助用户看清任务、项目或学习计划的当前位置、完成度、风险状态和下一步行动。

## Structure

```text
progress-locator/
├── SKILL.md
├── scripts/
├── references/
├── assets/
├── LICENSE.txt
└── README.md
```

## Notes

- `SKILL.md` 是 AI 使用入口。
- `references/output-templates.md` 放完整输出模板。
- `scripts/` 与 `assets/` 当前仅保留占位文件。
