# Output Templates

## 阶段标记器

```text
当前位置：[阶段名称]
阶段判断：[为什么是这个阶段]
下一里程碑：[进入下一阶段需要完成什么]
```

## 进度仪表盘

```text
总体进度：[百分比]
已完成：
- [完成项 1]
- [完成项 2]

剩余：
- [剩余项 1]
- [剩余项 2]

估算依据：[用完成项/总项或关键里程碑解释]
```

## 状态诊断仪

```text
健康度：[绿灯/黄灯/红灯/黑灯]
优势：
- [优势]

风险：
- [风险] -> [影响] -> [处理动作]

当前最需要关注：[单点问题]
```

## 位置锚定器

```text
当前关注点：[事项]
上游依赖：[前置条件]
当前位置：[它在整体中的作用]
下游影响：[完成后解锁什么]
```

## 下一步导航

```text
推荐下一步：[具体动作]
预计耗时：[时间]
完成标准：[验收条件]
备选路径：
- 如果 [条件]，则 [动作]
```

## 完整输出骨架

```text
现状快照

1. 当前位置：[阶段]
2. 总体进度：[百分比 + 依据]
3. 当前状态：[健康度 + 风险]
4. 下一步：[单条动作 + 验收标准]
```
