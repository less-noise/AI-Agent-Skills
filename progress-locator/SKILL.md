# Progress Locator

定位仪用于把模糊的“我现在在哪、还差多少、接下来做什么”转成清晰、量化、可行动的现状判断。先定位，再建议。

## Four-Question Scan

每次使用先回答四个问题：

1. 位置：当前处于起点、早期、中期、后期、收尾、完成、停滞中的哪一段。
2. 进度：完成了多少，还剩多少；优先用百分比或分项完成度。
3. 状态：顺畅、卡壳、有风险、停滞。
4. 下一步：继续、调整、暂停、求助或复盘。

## Three Dimensions

| Dimension | Purpose | Examples |
| --- | --- | --- |
| 时间轴 | 判断阶段 | 起步、推进、爬坡、冲刺、收尾、停滞 |
| 深度 | 判断掌握层级 | 认知、操作、应用、精通 |
| 风险 | 判断健康状态 | 绿灯、黄灯、红灯、黑灯 |

## Five Tools

1. 阶段标记器：快速说明当前位置和进入下一阶段的里程碑。
2. 进度仪表盘：拆分模块，量化总体与分项完成度。
3. 状态诊断仪：识别优势、风险、速度、质量、动力。
4. 位置锚定器：说明当前关注点在整体中的位置。
5. 下一步导航：给出单条最自然的下一步行动和备选路径。

## Output Rules

- 快速确认：只输出阶段 + 进度 + 下一步。
- 详细分析：输出阶段、分项进度、风险、下一步。
- 问题诊断：重点输出健康度、风险和调整动作。
- 进度汇报：重点输出完成项、剩余项和阻塞。

## Quality Checklist

- 有明确阶段，不只说“差不多”。
- 有量化依据，不只说“快完成了”。
- 有风险提示，不只报喜。
- 下一步足够具体，可以立即执行。
- 没有用过多指标制造新的困惑。
