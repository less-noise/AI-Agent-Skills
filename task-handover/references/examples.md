# Handover Examples

## 代码任务示例

```text
任务标题：修复登录接口 500 错误
任务类型：代码
当前状态：进行中（60%）
中断原因：上下文过长

原始需求："登录接口线上偶发 500，帮我排查并修复。"
完成标准：定位根因，修改代码，补充回归测试，说明验证结果。

已完成：
- 查看日志 -> 发现空 token 会触发 NoneType 错误。
- 检查 auth_service.py -> 确认缺少 token 判空。

待完成：
- [ ] 添加 token 判空和错误响应 -> 测试空 token 返回 401。
- [ ] 补充单元测试 -> 覆盖空 token、过期 token、正常 token。

关键约束：
- 不改变现有登录成功响应格式。
- 不引入新依赖。

接班指令：
继续修改 auth_service.py，先补空 token 分支，再运行登录相关测试。
```

## 写作任务示例

```text
任务标题：AI 产品竞品分析报告
任务类型：写作
当前状态：进行中（45%）

原始需求："写一份 3000 字竞品分析，对比 A、B、C 三个 AI 产品。"
完成标准：Markdown 报告，含对比表、优劣势分析、结论建议。

已完成：
- 确定结构 -> 背景、产品概览、对比表、分析、建议。
- 完成 A 和 B 的产品概览。

待完成：
- [ ] 补 C 产品概览。
- [ ] 制作横向对比表。
- [ ] 写结论建议。
```
