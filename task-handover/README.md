# Task Handover

中文名称：任务交接

## Purpose

生成标准化任务交接文档，让新 AI、新会话或接手人可以在信息损耗最小的情况下继续任务。

## Structure

```text
task-handover/
├── SKILL.md
├── scripts/
├── references/
├── assets/
├── LICENSE.txt
└── README.md
```

## Notes

- `SKILL.md` 是 AI 使用入口。
- `references/examples.md` 放完整交接示例。
- `scripts/` 与 `assets/` 当前仅保留占位文件。
