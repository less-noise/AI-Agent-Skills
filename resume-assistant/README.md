# Resume Assistant

中文名称：简历助手

## Purpose

帮助用户从信息收集、能力发掘、STAR 追问到简历成品输出，生成可投递的专业简历。

## Structure

```text
resume-assistant/
├── SKILL.md
├── scripts/
├── references/
├── assets/
├── LICENSE.txt
└── README.md
```

## Notes

- `SKILL.md` 是 AI 使用入口。
- `references/resume-examples.md` 放详细示例。
- `assets/resume-template.html` 是 HTML 简历模板。
- `scripts/generate_resume.py` 用结构化 JSON 渲染 HTML。
