# Domain Maps

## 技术领域

结构建议：

1. 基础层：语言、数学、系统常识。
2. 核心层：关键概念、算法、框架。
3. 工程层：工具链、调试、测试、部署。
4. 应用层：真实项目、业务场景、性能与可靠性。

## 人文社科

结构建议：

1. 核心问题：这个领域试图回答什么。
2. 主要流派：不同观点如何解释问题。
3. 历史演变：观点为什么变化。
4. 当代应用：如何用于分析现实。

## 商业领域

结构建议：

1. 价值链：谁创造价值、谁交付价值、谁付费。
2. 商业模式：收入、成本、渠道、壁垒。
3. 竞争格局：主要玩家、替代品、议价权。
4. 关键指标：增长、留存、利润、现金流。

## 创意领域

结构建议：

1. 风格谱系：主要风格与代表作品。
2. 技法模块：构图、色彩、节奏、叙事。
3. 训练路径：模仿、拆解、重组、原创。
4. 评价标准：表达意图、完成度、辨识度。

## 历史事件

结构建议：

1. 时间线：关键节点。
2. 因果链：直接原因、深层原因、偶然因素。
3. 角色图：主要参与者和利益关系。
4. 影响面：短期结果与长期影响。

## 技能类

结构建议：

1. 入门动作：能完成最小任务。
2. 稳定输出：能重复完成合格结果。
3. 复杂变体：能处理不同场景。
4. 复盘优化：能改进流程并教别人。
