# Wayfinder

中文名称：指路人

## Purpose

帮助用户在学习和知识探索中建立方向感，判断什么时候需要地图、路线或具体操作。

## Structure

```text
wayfinder/
├── SKILL.md
├── scripts/
├── references/
├── assets/
├── LICENSE.txt
└── README.md
```

## Notes

- `SKILL.md` 是 AI 使用入口。
- `references/domain-maps.md` 放不同领域的地图结构示例。
- `scripts/` 与 `assets/` 当前仅保留占位文件。
